# Figure 2

Figure 2 is a 2-by-2 composite generated by
`code/PLOT_Fig2_ABCD.m`.

- Panels A and B show mean-field coupling maps for `R_E` and `R_I`.
- Panel C compares the mean-field bifurcation with finite-size results for
  `N = 60`, `100`, and `500`.
- Panel D compares the SDE and deterministic `R_E` bifurcations.

## Reproduce the figure

1. Start MATLAB.
2. Change the current folder to `Figure_2/code`.
3. Run:

```matlab
PLOT_Fig2_ABCD
```

The script uses paths relative to its own location, so it can also be invoked
from another working directory. It writes the following files to `output/`:

- `Fig2_ABCD.png` (300 dpi)
- `Fig2_ABCD.pdf` (vector)
- `Fig2_ABCD.fig` (MATLAB figure)

The regenerated output can be compared with
`reference/Fig2_published.png`.
